# North prototype

The North prototype, hosted so voice (the microphone) works. Open https://hulewat.github.io/north-prototype/ in Chrome, Edge or Safari, allow the microphone, and hold Control to talk.

- **[HANDOFF.md](HANDOFF.md)**: the design, motion and interaction spec for engineering, with links into the source, plus a checklist to run against a build.
- **[source/](source/)**: the readable source. `cd source && npm install && node build.mjs` rebuilds `index.html` exactly.
- On the live prototype, press **D** for the motion dials and **T** to inspect any element's values.

Sample data only.
